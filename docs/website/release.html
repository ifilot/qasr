Adjustable illustrated shading

Choose 1–8 flat shades for atoms and molecular orbital surfaces. Three shades remain the default, and one shade uses a single midtone.

Use --shade-bands 5 for a single render or set image.shade_bands in a recipe. Contour width is controlled separately. Shade count reference.

qasr examples/CONTCAR.co --no-user-config \
  --config examples/illustrated.json --shade-bands 5 -o cobalt.png

Configuration and job schema versions remain 1. For the previous release’s drawing and animation features, see the symmetry guide.
