# Centered periodic context (M8)

Use neighboring xy cells to show periodic surroundings while keeping the
primary cell in full element colors. This extends the existing lattice-repeat
feature; it follows lattice vectors a/b, including skewed or rotated cells.
It does not assume that these vectors align with Cartesian X/Y.

```sh
# One neighbor on each side: a centered 3×3×1 patch, with muted image atoms.
build/qasr CONTCAR --expand-xy 1,1 --view top \
  --config presets/illustrated.json -o muted.png

# The same patch with neutral greyscale image atoms.
build/qasr CONTCAR --expand-xy 1,1 --image-colors greyscale \
  --view top --config presets/illustrated.json -o greyscale.png

# Five cells along a, three along b. All copies keep their element colors.
build/qasr CONTCAR --expand-xy 2,1 --image-colors normal -o full-color.png
```

`NX,NY` count additional cells **on each side**. Their integer ranges are
`[-NX,NX]`, `[-NY,NY]`, with z origin zero, producing
`(2*NX+1) × (2*NY+1) × 1` copies. Each count is 0..511. `0,0` disables
centered expansion. Nonzero expansion cannot be combined with a nontrivial
`--repeat`; reset the other setting to `1,1,1` or `0,0` when overriding a preset.
The existing atom, allocation, bond and enumeration limits still apply.

Strict JSON uses:

```json
{
  "geometry": {
    "expand_xy": [1, 1],
    "image_colors": "muted"
  },
  "camera": {"view": "top"}
}
```

CLI settings override their JSON counterparts. The default image style is
`muted` for centered expansion and `normal` otherwise. Explicit `normal`
keeps every copy in full colors. `muted` desaturates/lifts copy RGB toward
white while retaining a small element hue; `greyscale` uses a lightened neutral
luminance. Primary atoms always retain their selected element palette, including
custom colors. RGB conversion occurs before shading/AA, with alpha, sphere radii,
bond rules and depth tests preserved. It does not simulate transparency.

Primary-cell identity is the translation `[0,0,0]` after source fractional
wrapping. Input atoms outside the original coordinate range are wrapped before
copying, so each source atom has exactly one primary instance and no boundary
duplicates are added. Atoms straddling an outline are colored by their center's
cell identity; their spheres are drawn whole. `--inspect-scene` exposes each
sphere's `origin`, `primary_cell`, element and effective RGBA.

Centered expansion outlines the primary unit cell. Using muted/greyscale with
legacy positive-direction `--repeat` also switches to the primary-cell outline;
plain `--repeat` with normal colors keeps the existing supercell outline. Cell
lines remain depth-tested, and `--cell off` hides them. All atom copies and
clipped bonds contribute to camera fitting; bonds keep their existing gray
palette and clip against the expanded skewed parallelepiped. No extra z copies
are generated by `--expand-xy`; the ordinary unit-cell z periodicity remains.

Labels, axes, legends and the physical scale bar retain their existing behavior
and work limits. Legend counts cover all displayed instances, and its swatches
use the full primary element colors even when muted copies occur first in
scene order. Large labeled expansions can reach the existing visibility-work
limit; the default expansion does not enable labels.

Seven regression groups cover independent centered-versus-translated bond
geometry, counts/unique origins, boundary wrapping, primary outline corners,
alpha/palette preservation, strict input/conflict/instance limits, restored
legacy pixels, thread determinism, legend swatches and all 20 real slab inputs.
The complete Release and leak-enabled sanitizer suites include these checks.

Generate the comparison galleries with:

```sh
python3 tools/render_examples.py build/qasr --expand-xy 1,1 \
  --image-colors muted --output artifacts/m8/muted
python3 tools/render_examples.py build/qasr --expand-xy 1,1 \
  --image-colors greyscale --output artifacts/m8/greyscale
```

Each gallery retains PNG/input/preset hashes and fitted-camera metadata. The
original M0–M7 milestone list is complete; M8 is this user-requested addition.
Broader OUTCAR version/real-MD coverage remains a documented validation gap.

The accepted i9-10900K WSL workstation measured a 3×3×1 greyscale patch using
30 warm-cache samples after three warmups, automatic threads and native storage.
Median process times were 36.24/62.94 ms for shaded 512px / illustrated 768px
Co slab views, and 32.08/53.18 ms for Pd/ceria. Raw samples, stages, RSS,
input/binary hashes and PNGs are retained in `artifacts/m8/performance.json`.
These are observed timings, including PNG close/rename but excluding fsync,
under uncontrolled host load/governor; they are not new universal latency gates.
